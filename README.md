# Furniture Design

A website for a furniture designer and maker, with a tool that turns rough sketches and typed or spoken ideas into 3D furniture designs.

Created by **Karan Kumar**.

## Overview

Customers and designers often start with a rough idea rather than a perfect drawing. This project lets them sketch freely, describe what they want in words, and see it come to life as a 3D model. Past designs and materials are stored so they can be reused and refined.

## Features

- **Sketch-to-3D design tool**: draw any furniture design; the software understands rough sketches, helps clean them up, and builds the 3D model from the actual drawing.
- **Full drawing toolset**: sketching tools modelled on the Windows 11 Paint feature set.
- **AI furniture generator**: type the furniture you want (for example, a 4x5 almirah with 3 doors, 3 drawers and 1 corner cabinet) and the AI builds a design that follows the details, not just a plain box.
- **Voice input**: speak your prompt instead of typing it.
- **Saved designs and materials**: store previous designs and materials for reuse.
- **Designer workflow**: designers can start a new design from a rough sketch, with no need for a perfect drawing.
- **Feedback and reviews**: customers can leave feedback and reviews.
- **Multilingual**: the site supports multiple languages.
- **Customizable branding**: business name and contact information can be set to match the designer.

```bash
cd Furniture-design
```

Then open `index.html` in your browser, or serve the folder with a local server such as the VS Code Live Server extension.
